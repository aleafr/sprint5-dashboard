Web Dashboard – Projeto Sprint 5

Este projeto foi desenvolvido como parte da Sprint 5 do curso de Análise de Dados da TripleTen.
O objetivo foi criar e publicar um aplicativo web interativo utilizando Streamlit, incluindo gráficos simples gerados com pandas e plotly-express.

📌 Funcionalidades do aplicativo

O aplicativo contém:

Um cabeçalho com texto;

Um botão ou caixa de seleção;

Um histograma utilizando dados do arquivo vehicles_us.csv;

Um gráfico de dispersão (scatter plot) utilizando o mesmo dataset.
